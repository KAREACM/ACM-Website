# 🚀 ACM Website - Quick Command Reference

## Deployment Command Cheat Sheet

### Pre-Deployment (Local Machine)

```bash
# 1. Build Backend
cd backend
npm run build
cd ..

# 2. Build Frontend  
cd my-next-app
npm run build
cd ..

# 3. Verify builds exist
ls backend/dist/         # Should show: app.js, server.js, config/, etc.
ls my-next-app/out/      # Should show: index.html, _next/, etc.
```

### cPanel Deployment (After Uploading)

#### Backend Setup (SSH)
```bash
# Navigate to backend
cd ~/public_html/api

# Install production dependencies
npm install --production

# Test backend is working
curl http://127.0.0.1:5000/api/blogs

# Start with PM2 (if available)
pm2 start dist/server.js --name "acm-api"
pm2 save
```

#### Frontend Setup (File Manager)
```bash
# Set proper permissions
chmod -R 755 ~/public_html/www/

# Verify files exist
ls ~/public_html/www/        # Should show: index.html, _next/, etc.
```

### Post-Deployment Testing

```bash
# Test Frontend
curl https://yourdomain.com           # Should return HTML

# Test Backend
curl https://yourdomain.com/api/blogs # Should return JSON

# Test MongoDB Connection
curl https://yourdomain.com/api/teams

# View Backend Logs
pm2 logs acm-api

# Monitor Processes
pm2 status
pm2 list
```

## Troubleshooting Commands

```bash
# Check if Node.js app is running
pm2 status
ps aux | grep node

# View error logs
pm2 logs acm-api
tail -f ~/.pm2/logs/acm-api-error.log

# Test MongoDB connection
mongo "mongodb+srv://root:root@cluster0.cnsqhiu.mongodb.net/acm_website"

# Check port usage
netstat -tuln | grep 5000
lsof -i :5000

# Restart backend
pm2 restart acm-api

# Stop backend
pm2 stop acm-api

# Delete backend process
pm2 delete acm-api

# Reinstall dependencies
cd ~/public_html/api
rm -rf node_modules package-lock.json
npm install --production
```

## Security Commands

```bash
# Secure file permissions
chmod 644 ~/public_html/api/.env.production      # Read-only
chmod 755 ~/public_html/api/                     # Executable
chmod -R 755 ~/public_html/www/                  # Frontend readable

# Verify sensitive files are protected
find ~ -name ".env*" -type f              # Find env files
find ~ -name "package.json" -type f      # Find package.json

# Check .htaccess is in place
ls -la ~/public_html/api/.htaccess
ls -la ~/public_html/www/.htaccess
```

## Quick Deployment Script (Automated)

```bash
#!/bin/bash
# Run this in the project root to prepare for deployment

# Build both projects
cd backend && npm run build && cd ..
cd my-next-app && npm run build && cd ..

# Create archives for upload
tar -czf acm-backend.tar.gz backend/dist backend/package.json backend/.env.production backend/.htaccess
tar -czf acm-frontend.tar.gz my-next-app/out my-next-app/.htaccess

echo "✅ Deployment packages ready:"
echo "   - acm-backend.tar.gz"
echo "   - acm-frontend.tar.gz"
```

## Backup & Recovery

```bash
# Backup Backend
tar -czf backup-backend-$(date +%Y%m%d).tar.gz ~/public_html/api

# Backup Frontend
tar -czf backup-frontend-$(date +%Y%m%d).tar.gz ~/public_html/www

# Restore Backend
tar -xzf backup-backend-*.tar.gz -C ~/public_html/
```
